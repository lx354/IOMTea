## 2. 树莓派引脚说明

树莓派 5 的 40 个 GPIO 引脚有固定编号。将树莓派 USB 接口朝下、GPIO 引脚朝上放置时，左上角第一根为 **Pin 1 (3.3V)**。

以下为本项目使用的引脚位置（`●` 标记对应引脚）：

```
                  ┌─────────────────────────────┐
  Pin 1  (3.3V) ──┤  ● ···· ···· ···· ···· ···· │
  Pin 2  (5V)   ──┤  ● ···· ···· ···· ···· ···· │
                  │  ···· ···· ···· ···· ···· ···· │
  Pin 6  (GND)  ──┤  ··· ● ···· ···· ···· ···· ·· │
                  │  ···· ···· ···· ···· ···· ···· │
  Pin 7  (GPIO4) ─┤  ···· ··● ···· ···· ···· ···· │
                  │  ···· ···· ···· ···· ···· ···· │
  Pin 11 (GPIO17)─┤  ···· ···· ··● ···· ···· ···· │
                  └─────────────────────────────┘
```

### 引脚速查表

| 引脚编号 | 名称 | 用途 | 建议线色 |
|----------|------|------|---------|
| Pin 1 | 3.3V | DHT22 供电 | 红色 |
| Pin 2 | 5V | PIR 供电 | 红色 |
| Pin 6 | GND | 公共地线 | 黑色 |
| Pin 7 | GPIO4 | DHT22 数据线 | 黄色 |
| Pin 11 | GPIO17 | PIR 信号线 | 蓝色 |

## 3. 接线步骤

### 3.1 DHT22 温湿度传感器

DHT22 有 4 个引脚（从左至右：VCC, DATA, NC, GND）。**NC 引脚悬空，不接任何线。**

```
                    DHT22 (正面)
                  ┌──────────────────┐
     红色 → Pin 1 ─┤ VCC  DATA  NC  GND │
     黄色 → Pin 7 ─┤                   │
     黑色 → Pin 6 ─┤                   │
                  └──────────────────┘
                       4.7kΩ (上拉电阻)
                    ┌─────┬─────┐
            Pin 1 ──┤           ├── DATA (黄色)
                    └───────────┘
```

接线步骤：

1. **VCC (左1)** → 红色杜邦线 → **树莓派 Pin 1 (3.3V)**
2. **DATA (左2)** → 黄色杜邦线 → **树莓派 Pin 7 (GPIO4)**
3. **NC (左3)** → **悬空，不接线**
4. **GND (左4)** → 黑色杜邦线 → **树莓派 Pin 6 (GND)**
5. **上拉电阻**：将 4.7kΩ 电阻跨接在 3.3V 和 DATA 线之间，确保空闲时 DATA 线为高电平

> 4.7kΩ 上拉电阻的作用是在 DHT22 不驱动 DATA 线时将其维持在 3.3V，防止信号浮动导致误读。

### 3.2 PIR 人体红外传感器

PIR 有 3 个针脚。**重要：PIR 是 5V 设备，输出也是 5V，但树莓派 GPIO 只能承受 3.3V，所以必须用电阻分压降压！**

```
                    PIR (正面朝向自己)
                  ┌──────────────────┐
                  │     半球透镜       │
                  │  OUT   VCC  GND   │
                  └──────────────────┘
                         │
                     🔵 蓝线 (OUT → 分压器)
                         │
                    ┌────┴────┐
             1kΩ ├─GND       3.3V──┤ 2kΩ
                 │   (Pin 6)  (Pin 1)│
                 └────────┬─────────┘
                          │
                     🔵 蓝线 → GPIO17 (Pin 11)
```

**步骤：**

1. **PIR VCC（中间针脚）** → 杜邦线（红）→ **树莓派 Pin 2 (5V)**
2. **PIR GND（最右针脚）** → 杜邦线（黑）→ **树莓派 Pin 6 (GND)**
3. **PIR OUT（最左针脚）** → 蓝线 → **分压器**
4. **分压器接法（关键！）**：
   - 在面包板上，把 PIR OUT 的蓝线插在一行
   - 2kΩ 电阻从这一行接到 3.3V (Pin 1)
   - 1kΩ 电阻从这一行接到 GND (Pin 6)
   - 再从这一行引一根蓝线到 **树莓派 Pin 11 (GPIO17)**

> **注意**：PIR OUT 输出 5V 信号，树莓派 GPIO 耐受电压为 3.3V，直接连接会损坏引脚，必须使用分压器。

### 3.3 USB 摄像头

连接至树莓派任意 USB 接口即可。

## 4. 电压分压器说明（为什么需要）

PIR 输出 5V 信号，但树莓派 GPIO 只能接受 3.3V。直接接会烧引脚。

分压器用两个电阻把 5V 降到 3.3V：

```
          PIR OUT (5V)
              │
              ├──── 2kΩ ──── 3.3V (Pin 1)
              │
              ├──── 1kΩ ──── GND  (Pin 6)
              │
          GPIO17 (3.3V 安全输入)
```

公式：`Vout = 5V × 1kΩ / (2kΩ + 1kΩ) ≈ 1.67V`（在 3.3V 耐受范围内）

> 如不接分压器将 PIR 输出直连树莓派 GPIO，5V 电压会损坏树莓派引脚。

## 5. 常见接线错误

| 错误 | 后果 | 正确处理 |
|------|------|----------|
| DHT22 的 NC (左3) 接线 | 数据不稳定 | 左3 悬空 |
| PIR OUT 直连 GPIO 未加分压 | GPIO 引脚烧毁 | 必须加 1kΩ + 2kΩ 分压 |
| 杜邦线未插牢 | 接触不良，数据中断 | 杜邦线插到底 |
| 面包板行列混淆 | 电路不通 | 面包板竖排连通 |
| DHT22 接 5V 而非 3.3V | 可能损坏传感器 | DHT22 仅接 3.3V (Pin 1) |
| 传感器与树莓派地线不共地 | 读数异常 | 所有 GND 接至同一地线 (Pin 6) |

## 6. 软件安装

将 `hardware/raspberry-pi/` 目录传输到树莓派（可通过 U 盘或 `scp`），然后：

```bash
chmod +x install.sh
./install.sh
```

脚本自动安装 Python 依赖并下载 YOLO 人体姿态模型。

> YOLO 模型下载较慢时可使用代理，或手动将 `yolov8n-pose.pt` 放入当前目录。

---

## 7. 运行

```bash
# 编辑配置：设置 PIN 与服务器地址
nano config.py

# 启动终端（需要 sudo 获取 GPIO 权限）
sudo python3 main.py
```

**`config.py` 关键配置项**：
- `PIN` — 服务器注册的设备 PIN（默认 `000000`）
- `MQTT_BROKER` — IOMTea 服务器 IP 地址
- `READ_INTERVAL` — 采集间隔，默认 20 秒

## 9. 断电与重启

树莓派无硬件电源开关，直接拔 USB-C 电源线断电。重新通电后自动启动系统。如需配置开机自启，参考 `install.sh` 中的 systemd 服务设置。

> **接线核对**：Pin 1=3.3V, Pin 2=5V, Pin 6=GND, Pin 7=GPIO4, Pin 11=GPIO17。引脚电压有误可能损坏设备。
